# 小白桌宠

使用 PySide6 制作的 Windows 透明桌面宠物。

## 使用方法

- 鼠标左键拖动：移动桌宠。
- 单击角色：依次触发跳跃、压扁回弹、左右抖动，并随机显示中文气泡。
- 鼠标滚轮：调整桌宠大小。
- 在其他窗口点击鼠标：小狗会伸爪点击自己的迷你鼠标。
- 连续敲键盘：小狗会亮出小键盘同步打字；程序只感应按键动作，不记录文字内容。
- 空闲时会偶尔点头、伸懒腰或主动搭话。
- 鼠标右键：选择预设大小、切换输入跟随、切换始终置顶或退出程序。

双击 `dist\小白桌宠.exe` 即可运行，不需要目标电脑另装 Python。

## 重新打包

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\build.ps1
```

程序使用项目内 `.venv` 环境和 `pet.spec` 配置进行单文件、无控制台打包。
